## 新增需求

### 需求:可配置等待超时时间
系统必须支持通过 `waittimeout` 输入参数自定义部署等待超时时间，默认值为 300 秒。参数必须为正整数。

#### 场景:使用默认超时
- **当** 用户指定 `wait=true` 但未指定 `waittimeout`
- **那么** 系统使用 300 秒作为等待超时

#### 场景:自定义超时
- **当** 用户指定 `wait=true` 且 `waittimeout=600`
- **那么** 系统使用 600 秒作为等待超时

#### 场景:超时值无效
- **当** 用户指定 `waittimeout` 为非正整数（如 `abc`、`-1`、`0`）
- **那么** 系统必须报错退出并提示超时值无效
